# Hellgato 0.0.1 beta

MIT-licensed Windows bridge for one stock Mirabox N4 Pro and the official Stream Deck application.

- Ten LCD keys, four dial rotations, app-rendered images and touch page switching.
- Structural compatibility checks, persistent identity and USB reconnect handling.
- Connection-aware controls with separate profile progress and completion status.
- Dark desktop interface with File, Settings and Help menus, keyboard navigation and a separate preferences window.
- Eleven interface languages, with JSON catalogs for community translation.
- Profile import/export, tray operation and optional Windows sign-in startup.
- Per-user installer with bundled runtimes. Stream Deck and plugins are installed separately.

Pair `127.0.0.1:5343` in Stream Deck's Network settings once on a new PC. Closing the window keeps Hellgato in the tray; use Exit to stop it.

The installer is unsigned. The current compatibility resolver has been validated on Stream Deck 7.6.0.23012. Preparation changes process memory without modifying the executable on disk. Simultaneous use with a genuine Stream Deck + is outside this beta's scope. Encoder release/hold, touch alignment, sustained animation and reboot recovery need further hardware validation.

Personal profiles are not included. See the README for setup, local data and contribution instructions.
