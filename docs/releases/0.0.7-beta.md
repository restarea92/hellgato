# Hellgato 0.0.7 beta

Configure sleep timing and screensavers in Stream Deck. Hellgato now plays saved static and animated screensavers directly through the N4 Pro SDK, preserving the saved animation timing and avoiding separate image uploads for every key.

- Sleep turns the screen off when no screensaver is configured. With a screensaver, the display fades to its minimum brightness and knob lighting turns off.
- Wake restores action images before fading the display and knob lighting back up, avoiding the blank-screen flash during restoration.
- Adds full LCD images, full-screen and individual-key color fills, logo display and per-device idle-timeout persistence.
- Simplifies the README, explains stock-firmware dial limitations, and lists the upcoming N4 Pro plugin controls.

Five-minute idle activation, screensaver dimming and wake behavior were confirmed on the test N4 Pro with Stream Deck 7.6.0.23012. Automated checks cover the display commands, saved screensaver loading, animation timing and sleep/wake transitions.

The Advanced standby-image setting remains unsupported and may disconnect the virtual device. N4 Pro does not report dial releases, so actions that depend on holding or releasing a dial cannot be reproduced accurately. Some manual Sleep sequences expose only brightness changes and still wait for the zero-brightness command before switching the screen off.

Run the Windows installer to update your existing installation. Your settings and profiles are retained.
