# Hellgato 0.0.4 beta

Replaces the custom File, Settings and Help popup windows with standard menus.

Menus open beside their buttons at the window's current position, including on displays with negative desktop coordinates. Moving the main window dismisses an open menu; reopening it uses the new position. Existing commands, shortcuts, translations and disabled states are retained.

Includes the adaptive touch strip feedback scheduling from 0.0.3 beta and the dial click fix from 0.0.2 beta.

Run the Windows installer to update your existing installation. Your settings and profiles are retained.
