# Hellgato Stream Dog 0.1.2

The Windows app now runs through the separated Hellgato SDK and a dedicated Mirabox USB worker. The installer bundles both runtimes; settings, remembered devices and Stream Deck profiles are retained.

- Fixes black LCD keys on first connection and USB reconnection.
- Keeps the virtual network dock available during USB reconnection and Stream Deck restarts, allowing automatic reconnection.
- Returns the N4 Pro to its standalone screen when Stream Deck closes.
- Preserves normal button and touch images across profile changes and sleep/wake.
- Updates application, taskbar, tray and shortcut icons while retaining existing app and installer artwork.

Physical checks on N4 Pro E firmware `V4.N4 Pro E.02.010` with Stream Deck `7.6.0.23012` covered initial display, USB reconnection, Stream Deck exit/restart, buttons, knobs, touch, profile/page changes, brightness and sleep/wake.

Known limitations: closing only Hellgato can leave the last image visible for tens of seconds before the device returns to standby. Restarting only Hellgato while Stream Deck stays open requires manual network pairing. N4 dial buttons do not provide physical release events, so hold and press-and-turn actions remain unsupported.

Run `Hellgato-0.1.2-Setup.exe` to update. Setup closes existing Hellgato and Stream Deck processes automatically. This is a manual Windows release; npm publication and automated deployment remain deferred.
