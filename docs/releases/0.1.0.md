# Hellgato Stream Dog 0.1.0

Hellgato's Windows client is now **Hellgato Stream Dog**. The first stable release adds ten-key startup, USB reconnection and native knob brightness controls for Mirabox N4 Pro E.

- Stream Deck prepares the 5×2 layout on every launch, including launches without USB hardware connected. All ten keys remain available when the device connects.
- USB reconnection restores the hardware connection while keeping the virtual network device connected.
- Hellgato respects manual Stream Deck shutdown and reconnects when you open Stream Deck again.
- Adjust knob brightness in Stream Deck's device settings. Changes apply immediately, save independently from display brightness, and restore after sleep.
- The device list shows names, assigned Stream Deck serials and live USB connection status. Disconnected devices remain listed, and saved physical identities preserve their assigned serials across connections and client restarts.
- A new pixel dog holding a Hellgato controller appears in the application icon.
- The installer displays an app-closing notice, closes Stream Deck and Hellgato, removes the verified previous installation and installs into `%ProgramFiles%\Hellgato` with administrator permission. Settings, device identity and Stream Deck profiles are retained; per-user data stays in `%LOCALAPPDATA%\Hellgato`.
- The finish page offers separate checkboxes to launch Hellgato Stream Dog now and at Windows sign-in.

Startup without USB, the 5×2 layout and both rightmost keys, USB reconnection, manual Stream Deck shutdown/relaunch and native knob brightness were verified with Stream Deck 7.6.0.23012 and N4 Pro E firmware `V4.N4 Pro E.02.010`. Stream Deck 7.5.1 was tested with an earlier beta.

The device registry has automated coverage for persistence, serial matching and identity conflicts. Physical identity recording and LCD button images were also verified after the Program Files migration. Only one registered N4 Pro can be active at a time. Devices without a hardware serial use their USB path, so changing ports may prevent recognition.

Migration from the previous per-user 0.0.7-beta installation to Program Files was verified, including old-program removal, retained settings and Windows uninstall registration. Installer migration and startup-option checks pass; the interactive finish page and elevation under a different Windows account still need manual verification.

The installer is unsigned. Dial holds and release-dependent actions remain limited by the stock firmware. The Advanced standby-image setting remains unsupported and may disconnect the virtual device. Windows reboot recovery, broader touch alignment, extended use and simultaneous use with a genuine Stream Deck + remain unverified.

Run `Hellgato-0.1.0-Setup.exe` to update, then open Stream Deck yourself. During normal use, Hellgato Stream Dog never launches Stream Deck automatically. After a Stream Deck update, close it and use **Prepare Stream Deck** if startup support needs refreshing.
