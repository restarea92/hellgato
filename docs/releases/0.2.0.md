# Hellgato Stream Dog 0.2.0 Beta

The Windows app now uses a Rust manager, Node headless core and independent Rust
device adapters. The installer bundles all runtime dependencies and contains no
Python runtime or Python worker.

- Compose keys, touch strip and screensavers into one device canvas. N4 Pro
  receives whole-display frames with bounded queues and a dynamic rate up to 60 fps.
- Manage devices, official and external `.hga` adapters, settings and tray lifetime.
- Restore independent N4 Pro knob brightness in Stream Deck, including saved
  levels and sleep/wake behavior.
- Warn about untested Stream Deck builds and device firmware without blocking
  core connection. Native layout patches still require matching structures.
- Back up each paired device's profiles alongside shared plugins, icons, settings
  and its virtual identity. Choose default or external storage; rename, reorder
  and delete managed snapshots.
- Remove owned legacy Python workers and installed runtime files during upgrade
  while retaining user settings, profiles and plugins.

## Installation

Close Stream Deck, run `Hellgato-0.2.0-Setup.exe`, then open both apps. Initial
Network Device pairing may require adding `127.0.0.1:5343` manually. Existing
paired virtual identities are retained. Check the accompanying SHA-256 sidecar.

## Beta verification and limits

N4 Pro E display, keys, dials, touch, screensaver restoration and knob brightness
were confirmed on physical hardware with Stream Deck 7.6.0.23012 and firmware
V4.N4 Pro E.02.010. N4/TS10N4 and 293S/TS115 compatibility adapters are included
for community testing; their physical behavior is unverified. Multiple physical
devices remain unverified, with one Mirabox device allowed per model family.

New host builds can connect with warnings, but startup layout preparation and
private automatic rescan may be unavailable. Genuine Stream Deck + coexistence,
dial holds/releases, standby-image upload and RGB effect controls are unsupported.
Backups are folders with per-file digests; automatic restore is not included.
Close Stream Deck for a consistent snapshot.

This is a public prerelease, not an automatic-update rollout. The previous
[0.1.8 release](https://github.com/restarea92/hellgato/releases/tag/v0.1.8)
remains available. Report exact device/firmware, host build and reproduction steps
without sharing `control.json` or `native-ui.json` authentication tokens.

See the [beta guide](../compatibility/stream-dog-rust-beta.md) and
[adapter development guide](../adapters/frame-adapter-guide.md).
