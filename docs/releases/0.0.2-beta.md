# Hellgato 0.0.2 beta

Fixes repeated N4 Pro dial clicks getting stuck in the pressed state.

The device sends a click without a separate release event. Hellgato now forwards each click as a press followed by a release, so Stream Deck actions can respond to every click, including toggles that start and stop on successive presses.

This models a click; it does not add support for holding a dial down. Touch strip animation performance is unchanged in this patch.

Run the Windows installer to update your existing installation. Your settings and profiles are retained. Stream Deck and plugins are installed separately.
