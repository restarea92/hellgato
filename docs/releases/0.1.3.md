# Hellgato Stream Dog 0.1.3

- Allows N4 Pro firmware versions outside the historical `V4.N4 Pro E.02.010` baseline to attempt a connection. Model, required capabilities, valid firmware reads and firmware consistency checks remain enforced. Device firmware is not modified.
- Preserves firmware error codes, bounded error messages, stack traces and operation details in local diagnostics. Records discovered firmware and successful device connections, including reconnections.
- Keeps the original connection failure when cleanup also fails, with cleanup errors logged separately.

Unverified firmware remains experimental; admission does not establish hardware compatibility. Issue #6 has no confirmed root cause. No physical hardware validation was performed for this patch. Automated firmware, model/capability, lifecycle and diagnostic regression checks cover the changed behavior.

Run `Hellgato-0.1.3-Setup.exe` to update. This is a manual Windows release; npm publication and automated deployment remain deferred.
