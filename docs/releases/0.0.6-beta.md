# Hellgato 0.0.6 beta

Updates the README and in-app artwork with an angled view of the 3D Hellgato controller, featuring the flame face and four dials. Windows and tray icons use the matching front view.

The README now illustrates the input and display paths with a white-background animation averaging 24 fps. The repository also includes an offline browser view and individual 3D device assets, with early animation drafts removed.

Documentation clarifies profile import behavior, current dial and display limitations, and the remaining hardware validation work.

Run the Windows installer to update your existing installation. Your settings and profiles are retained.
