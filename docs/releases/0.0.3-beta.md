# Hellgato 0.0.3 beta

Improves touch strip animation delivery by adapting Stream Deck's feedback checks to screen activity.

Screen update requests enable a 16 ms check interval. After two seconds without new requests, that feedback composer returns to Stream Deck's original idle wait. A new request wakes it again. The adjustment applies only to the running process; the Stream Deck executable on disk stays unchanged.

On a Mirabox N4 Pro with Stream Deck 7.6.0.23012, four 30 fps test animations delivered about 30 fps per strip region, including after stopping and restarting them. Neither measured animation segment contained a gap longer than 80 ms. Frame pacing can still vary by plugin and system; this is not a guarantee of 60 fps output.

Includes compatibility checks for the affected internal code and regression tests for activity expiry, wake-up, independent composers, and native register and stack preservation. The dial click fix from 0.0.2 beta is retained.

Run the Windows installer to update your existing installation. Your settings and profiles are retained. Stream Deck and plugins are installed separately.
